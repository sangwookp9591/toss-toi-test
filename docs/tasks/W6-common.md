# 6차 웨이브 공통 제약

모든 W6 작업자에게 적용한다. 개별 명세와 충돌하면 개별 명세가 우선한다.

- **비밀값:** `.env`를 열거나 출력하지 않는다. `cat .env`, `env`, `printenv`, 키가 들어간 요청 로그를 출력하지 않는다. API 키는 URL 쿼리스트링이 아니라 헤더로만 보내고, 오류 메시지·결과 JSON·테스트 스냅샷·보고서에 키나 키 일부가 들어가지 않게 한다. 키를 저장소 밖 서비스(붙여넣기 사이트, 이슈, 채팅)로 보내지 않는다.
- **git:** commit, push, branch 조작 금지. 커밋은 코디네이터가 한다.
- **설치:** 전역 설치 금지. 패키지마다 독립 `package.json`/lockfile 규칙을 지킨다(`docs/ARCHITECTURE.md` 저장소 규칙).
- **계약:** `contracts/`는 명세가 허용한 작업자만 수정한다.
- **포트:** 1차 웨이브는 `node scripts/dev-up.mjs`를 실행하지 않는다. 5173·5174·7100·7200·7300·7400·4873·9000 포트를 점유하지 않는다. 테스트는 임의 loopback 포트나 fake로 한다.
- **범위:** 명세의 Ownership 밖 파일은 수정하지 않는다. 필요하면 멈추고 코디네이터에게 묻는다.
- **보고:** 변경 파일, 실행한 명령과 결과(통과 수), 남은 위험을 짧게 적는다.
